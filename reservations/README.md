## Ce que ces fiches ne contiennent pas

Dépôt public. Sont volontairement absents :

- numéros de confirmation et codes confidentiels ;
- noms des voyageurs, adresses e-mail, numéros de téléphone privés ;
- montants payés et détail des tarifs ;
- numéros de siège, numéros de programme de fidélité.

Ces éléments restent dans les confirmations d'origine, hors de ce dépôt. Un numéro
de confirmation Booking accompagné de son code confidentiel permet d'annuler une
réservation sans aucune authentification : ça n'a pas sa place dans un historique
Git public.

Les montants conservés — dépôts de garantie, tarifs de parking — sont des politiques
d'établissement, publiques et utiles sur place.
